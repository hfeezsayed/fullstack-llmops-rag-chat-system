# Fullstack LLMOps RAG Chat System

## 🚀 Overview

This project is a production-ready full-stack LLMOps platform that enables users to chat with multiple documents using Retrieval Augmented Generation (RAG).

---

## 🧠 Architecture

Frontend → Next.js + Tailwind  
Backend → FastAPI  
AI Layer → LangChain Modular RAG  
Vector Database → FAISS  
Embeddings → HuggingFace / OpenAI switchable
